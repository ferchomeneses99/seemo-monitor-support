Política de privacidad

Responsable: Fernando Meneses. Contacto: kronpoxpepo@gmail.com.

Imagen, audio y emisiones

Métrica Studio recibe imagen y audio del accesorio conectado para previsualizarlos y enviarlos a los destinos que selecciones. Cada destino recibe una conexión directa desde el iPhone. La implementación actual no utiliza un servidor propio para retransmitir tu vídeo.

Conectar Facebook o YouTube

Cuando estas funciones estén disponibles, la autorización se realizará en el navegador del sistema. La app no solicita ni almacena tu contraseña de Facebook o Google. Recibe credenciales de autorización y los datos de perfiles, páginas o canales autorizados para mostrar tus destinos y crear, iniciar y cerrar emisiones a petición tuya.

El permiso de YouTube presenta una descripción amplia en la pantalla de consentimiento. La implementación usa recursos de canales y emisiones; no incorpora funciones para gestionar comentarios o calificaciones. El uso de información recibida de las API de Google se ajusta a la Política de datos de usuario de los servicios de API de Google, incluidos sus requisitos de uso limitado.

Almacenamiento y conservación

Las credenciales sociales, destinos autorizados e identificadores de emisiones pendientes se guardan en el llavero del iPhone, accesible cuando el dispositivo está desbloqueado y sin migración a otro dispositivo mediante ese elemento. Los destinos manuales y sus claves se conservan localmente. Las plataformas pueden vencer o revocar las credenciales y exigir una nueva autorización.

La implementación actual no mantiene una base de datos central propia de sesiones sociales, ni incorpora publicidad o analítica. No vende datos de usuario ni utiliza los datos recibidos de las plataformas para publicidad o entrenamiento de modelos.

Biblioteca de overlays

Al conectar la biblioteca de Métrica Studio, el iPhone consulta el sitio configurado y conserva su sesión web para acceder a tus diseños. Los overlays elegidos se guardan como copias locales editables. Cambiar goles, nombres, reloj o tarjetas en esas copias no modifica la salida original de la página. El sitio de la biblioteca conserva los datos de su propia cuenta y diseños; esta sesión es distinta de las autorizaciones para publicar en Facebook o YouTube. Al cerrar la sesión de la app se borran las copias de la biblioteca y su sesión web en ese iPhone.

Quién recibe los datos

Facebook, YouTube o el servidor que configures reciben las solicitudes de sus API y el vídeo y audio que transmitas a ese destino, junto a los datos técnicos necesarios para establecer la conexión. Sus propias políticas rigen el tratamiento que realizan. Consulta la política de Google y la política de Meta.

Tu control

Puedes detener una emisión y olvidar una sesión guardada. Si hay un cierre remoto pendiente, se conserva su identificador para reintentarlo. Una interrupción sin red puede impedir confirmar ese cierre; comprueba la plataforma si aparece el aviso.

Olvidar una sesión elimina las credenciales locales de esa cuenta, pero no borra vídeos publicados ni revoca por sí solo el permiso en el proveedor. El llavero puede conservar elementos después de desinstalar una app. Consulta las instrucciones de eliminación para desconectar también el acceso en las plataformas.

Consultas y solicitudes

Para consultas de privacidad o asistencia con tus datos, escribe a kronpoxpepo@gmail.com. No incluyas credenciales. Los cambios de esta política se publicarán aquí con su fecha de actualización.
